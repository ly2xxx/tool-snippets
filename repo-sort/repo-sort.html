Repository housekeeping

Repo Sort

Put every repository in one category. Each category becomes a GitHub topic, and anything you mark gets archived. When the Unsorted pile is empty, copy the plan at the bottom and run it with repo_sort.py.

Categories

The topic is what gets added on GitHub. Topics are lowercase letters, digits and hyphens. Renaming a topic removes the old one from its repositories the next time you run the plan.

Import

Paste or choose the file from python repo_sort.py snapshot OWNER -o repos.json to load or refresh your repositories with their descriptions and current topics. You can also paste a plan you copied earlier to restore it. Categories you already assigned are kept.

No repositories yet

On a computer with the GitHub CLI, run python repo_sort.py snapshot YOUR-USER -o repos.json, then open Import above and choose that file.

Plan

  1. Copy the plan and save it as repo-plan.txt next to repo_sort.py.
  2. See what would change, with nothing touched: python repo_sort.py apply repo-plan.txt
  3. Apply it: python repo_sort.py apply repo-plan.txt --yes. Running it again is safe; finished repositories are skipped.
  4. Afterwards, run python repo_sort.py snapshot OWNER -o repos.json and import it here to confirm GitHub matches.
